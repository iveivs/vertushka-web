## Стек

| Что | Чем | Появится |
| --- | --- | --- |
| Сборка | Vite | Спринт 1 |
| Язык | TypeScript (strict) | Спринт 1 |
| Стили | CSS Modules + CSS-переменные | Спринт 1 |
| Качество кода | ESLint + Prettier | Спринт 1 |
| UI | React 19 | Спринт 2 |
| Роутинг | React Router | Спринт 2 |
| Данные с сервера | TanStack Query | Спринт 3 |

| Формы | React Hook Form + Zod | Спринт 4 |
| Тесты | Vitest + Testing Library | Спринт 5 |

Библиотеки подключаются, когда до них доходит задача, а не заранее.
